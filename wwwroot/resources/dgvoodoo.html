DgVoodoo2

Многофункциональный патч\конвертер для старых игр, использующих DirectX до 9 включительно или API Glide (эмуляция 3д-ускорителей 3Dfx Voodoo). В случае с Touhou рекомендуется для применения вместе с Vpatch либо OpenInputLagPatch на современных Windows.

Функции:

  • Конвертация графического API в DirectX 11/12, улучшая совместимость с Windows 10/11 и исправляя некоторые недочёты.
  • Из п.1 вытекает возможность использовать Flip Presentation Model для игр в окне/без рамок, вместо Blt. Это позволяет выводить картинку игры напрямую на монитор, сильно снижая задержку от композитора.
  • Повышение разрешения игры и текстур через метод ближайшего соседа, билинейную интерполяцию и прочие.
  • 4. Изменение растяжения картинки в фуллскрине\окне.

Установка:

  1. Из /MS/x86 копируем конверторы D3D8.dll или D3D9.dll (Touhou 6-9.5 используют DirectX 8, Touhou 10+ — DirectX 9) в папку с запускным файлом игры.
  2. Заходим в dgVoodooCpl.exe. Нажимаем на кнопку Add и выбираем папку, где находится наша игра и DLL-файл.
  3. Стоит отметить, что кнопка «.\» добавляет в список папку, в которой находится файл dgVoodooCpl.exe.
  4. Нажимаем OK. В указанной папке должен появиться файл dgvoodoo.conf. Он и является конфигурационным.
  5. Через dgVoodooCpl.exe мы можем изменять dgvoodoo.conf. Если игр несколько, dgvoodoo.conf вместе с DLL можно копировать в другие папки.

Настройка dgVoodooCpl:

Через DgVoodoo можно сделать много полезных твиков. Всех их не перечислить, но здесь отмечены некоторые функции. При наведении на параметры появляются подсказки на английском языке.
Можно переключать режим окна/полного экрана в dgVoodooCpl.exe, но подобная настройка в Touhou (custom.exe) тоже может влиять на поведение.

Показ всех настроек конфига:

Пкм по любой области в dgVoodooCpl → Show all sections of the configuration. Это откроет нам доступ к продвинутым настройкам, вкладкам GeneralExt, GlideExt, DirectXExt.

Отключение водяного знака:

DirectX → Miscellanneous → dgVoodoo Watermark = снять галочку.

Включение Flip:

По умолчанию DgVoodoo не использует Flip т. к. это часть DirectX 12: General → Rendering → Output API = DirectX 12 Либо можно вне зависимости от граф. API принудительно включить: Вкладка GeneralExt → Presentation Model = flip_discard

Изменение разрешения игры:

DirectX → Resolution = Max либо другое значение.
Известно, что значения все кроме Unforced могут визуально сломать интерфейс в Touhou 6-8

Повышение чёткости текстур и спрайтов:

DirectX → Texturing → Filtering = Force Point Sampled
Данная опция во всех значениях кроме app driven ломает задние фоны в Touhou 6

Изменение метода апскейла общей картинки:

По умолчанию стоит Bilinear.

Увеличение изображения методом ближайшего соседа:

GeneralExt → Image Output → Resampling = Point Sampled

Включение оптимизированного фуллскрина(alt-tab без чёрного экрана):

В Touhou выставляем Fullscreen заранее. В dgVoodooCpl.exe:
  1. General → Appearance → на Full Screen ставим точку.
  2. Scaling Mode = Streched, keep Aspect Ratio или другое на ваше усмотрение.
  3. GeneralExt → FullScreen mode attributes → Fake = галочку ставим.
  4. Чтобы при сворачивании-разворачивании игра не растягивалась, в Windowed mode attributes ставим галочку на FullScreen Size и Borderless.

Помогите у меня курсор в оверлее thprac’а нельзя двигать!:

Это происходит из-за изменённого параметра Resolution, игра думает, что работает всё ещё в 640x480. Решение: GeneralExt → Miscellanneous → Free mouse = галочку ставим.

Отключение чёрного списка AMD видеокарт:

Создатель DgVoodoo ведёт чёрный список видеокарт AMD(RX 5xx, Vega, и т.д.), у которых есть проблема заполнения текстур сплошным цветом, проявляющееся в зависимости от драйвера. Для проверки на наличие проблемы чёрный список можно отключить: DirectXExt → Miscellaneous → Suppress AMD blacklist = галочку поставить.
