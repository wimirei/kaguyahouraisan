Установка дополнительных патчей через thcrap

thcrap позволяет не только устанавливать переводы, но и подключать дополнительные патчи, изменяющие игровой процесс, графику, музыку, интерфейс и многое другое.

thcrap не изменяет оригинальные файлы игры. Все патчи подключаются поверх игры и при необходимости могут быть отключены в любой момент.

Что такое стек патчей?

В thcrap все патчи загружаются в определённом порядке. Такой порядок называется стеком патчей (Patch Stack).

Если два патча изменяют один и тот же файл, приоритет будет иметь тот, который расположен ниже в списке.

Добавление нового патча

  1. Откройте программу thcrap_configure.exe.
  2. Выберите существующую конфигурацию (например русский перевод).
  3. Нажмите Edit configuration.
  4. Перейдите к списку патчей.
  5. Нажмите Add patch.
  6. Выберите нужный патч из списка репозиториев.
  7. Сохраните изменения.
После сохранения thcrap автоматически скачает все необходимые файлы выбранного патча.

Изменение порядка загрузки

Некоторые патчи должны загружаться после других.

Например:

  • сначала базовый перевод;
  • затем исправления текста;
  • после этого дополнительные модификации интерфейса.

При необходимости используйте стрелочки Вверх и Вниз, чтобы изменить порядок загрузки патчей.

Удаление патча

Если патч больше не нужен:

  1. Откройте thcrap_configure.exe.
  2. Выберите нужную конфигурацию.
  3. Удалите патч из списка.
  4. Сохраните изменения.

Оригинальные файлы игры останутся без изменений.

Обновление патчей

При запуске thcrap автоматически проверяет наличие новых версий установленных патчей.

Если обновления доступны, они будут скачаны автоматически.

Локальные патчи

Если вы скачали патч вручную или создали собственную модификацию, её также можно подключить через thcrap.

Для этого необходимо добавить папку патча в список используемых репозиториев конфигурации.

Полезные советы

  • Не удаляйте папку repos.
  • Не изменяйте содержимое папки bin.
  • Перед экспериментами с большим количеством модификаций рекомендуется создать отдельную конфигурацию.
  • Если игра перестала запускаться после установки нового патча, временно отключите его и проверьте совместимость.
