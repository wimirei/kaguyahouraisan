OpenInputLagPatch

OpenInputLagPatch - Более современный (в сравнении с Vpatch) патч для Touhou игр. Его цель — снизить задержку ввода(input lag), насколько это возможно. Поддерживает 6-18.5 части Touhou.

Функции:

  • Обеспечение минимально возможной задержки ввода.
  • Возможность вывода времени подготовки кадра в левом нижнем углу, для точной настройки BltPrepareTime.
  • Ускорение и замедление скорости воспроизведения реплеев.
  • Поддержка Direct3D9EX (модифицированный Direct3D9).
  • Возможность менять герцовку монитора в полноэкранном режиме.

Отличия OILP от Vpatch:

  • Для полной работоспособности требует, чтобы игра работала в directx 9. Это значит, что для Touhou 6-9.5 необходим d3d8to9 конвертер.
  • Не имеет настроек оконного режима.
  • OILP имеет единые файлы для всех частей Touhou.
  • Отсутствие AutoBltPrepareTime (только ручная настройка).

Конфигурационный файл:

Значения параметров указаны по умолчанию.rotect

GameFPS = 60 — Регулировка скорости игры.
ReplaySpeedControl = 1 — Разрешить контроллировать скорость реплея (Это заменит внутриигровой контроль скорости если он есть)
ReplaySkipFPS = 240 — FPS при ускорении реплея (Удерживайте левый CTRL во время просмотра реплея)
ReplaySlowFPS = 30 — FPS при замедлении реплея (Удерживайте левый SHIFT во время просмотра реплея)
BltPrepareTime = 2 — Количество времени в миллисекундах перед обновлением экрана для обновления логики игры. Меньше — лучше, но это увеличивает риск того, что игра не успеет исполниться вовремя и вызовет ещё больше задержки ввода.
Sleep = 1 — выбирает метод, используемый для ожидания между кадрами. 0: базовое ожидание (очень аккуратное, но сжирает процессор), 1: vpatch (значительно более высокий риск пропуска кадра в зависимости от ПК, но использует куда меньше ресурсов процессора)
D3D9Ex = 1 — Использовать Direct3D9Ex вместо Direct3D9 чтобы уменьшить задержку ввода на 0-2 кадра. Не оказывает эффекта на Touhou 9.5 и ниже, если d3d8to9 отсутствует.
FullscreenRefreshRate = 2 — Выбор частоты обновления в полноэкранном режиме игры. 0: Максимальная частота обновления, 1: 60 Гц, 2: Наибольшее кратное 60 (60 Гц, 120 Гц, 180 Гц, 240 Гц, и т. д.). Полезно для высокочастотных мониторов.
ShowOverlay = 1 — Рисует маленький оверлей в левом-нижнем углу экрана, показывающий, как долго занимает рендер игры. Полезен для настройки BltPrepareTime
DebugConsole = 0 — Открывает консоль для отладки.
DebugWait = 0 — Открывает окно при запуске, чтобы разрешить присоединение отладчика.
FixInputGlitching = 0 — Исправляет проблемы с заглючиванием управления, которые могут появиться в Touhou 6 и 7 если вы, к примеру, расфокусируете окно, пока игра загружается.
GameOverride = -1 — Перезаписывает алгоритм обнаружения игры на конкректную игру. Посмотрите games.h для возможных значений. ИЗМЕНЕНИЕ ЭТОГО ВЕРОЯТНО СЛОМАЕТ ВСЁ. Используйте только если вы на 100% уверены что оффсеты игры точно совпадают.

Установка:

  1. Скачайте архив и распакуйте его.
  2. Внутри 3 файла, которые нужно закинуть в папку с запускным файлом игры (OILP сам определяет, рядом с какой частью Touhou лежит).
  3. Через oilp_loader.exe осуществляется запуск игры.
Для Touhou 6-9.5 — скачать d3d8to9 конвертер и поместить файл (d3d8.dll) в папку с игрой.

Баги:

  • В современных Touhou при попытке выбрать разрешение НЕ равное 640x480(к примеру 1280x960 игра может вылетать. Решение заключается в добавлении этого разрешения в систему через Custom Resolution Utility.
