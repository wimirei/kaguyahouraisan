Locale Emulator

Locale Emulator — это небольшая бесплатная программа для Windows, которая позволяет запускать старые программы и игры с другой системной локалью, не изменяя настройки всей операционной системы. Для игроков Touhou она особенно полезна, потому что оригинальный .exe Touhou 6: Embodiment of Scarlet Devil не запускается если на компьютере отсутсвует японский язык.

Преимущества

  • Не нужно менять региональные настройки Windows или добавлять японский язык.
  • Работает только для выбранной программы.
  • Бесплатный и простой в использовании.

Использование:

После установки:
  1. Щёлкните правой кнопкой мыши по .exe файлу игры (Поддерживает vpatch и OpenInputLagPatch).
  2. Выберите Locale Emulator.
  3. Нажмите Run in Japanese.

Игра запустится с японской локалью.
