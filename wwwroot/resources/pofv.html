Игра по сети в Touhou 9: PoFV

Из-за плохой и нестабильной игры по сети в оригинальной игре, для игры по сети в Touhou 9: PoFV используются патч adonis/adonis2, а также виртуальная локальная сеть (RadminVPN/Hamachi).

Как играть:

  1. Cкачать архив игры с заранее установленными патчами
  2. В файле adonis2.ini, в строчке PlayerName поменять никнейм на свой.
  3. Запустить adonis2.exe

Написать:

  1. h - Для хоста игры.
  2. с - Для подключения к игроку.
  3. w - Для просмотра матча.

Если вы хост:

  1. Выбрать порт на котором будет сервер.
  2. Ожидать подключения игрока
  3. Выбрать задержку(1-10) или нажать Enter для использования автоматической.
  4. Выбрать сторону на которой будет ваш персонаж (левая или правая).

Если вы игрок:

  • Написать IP адрес хоста.
  • Написать порт хоста.
  • Ожидать когда хост продолжит настройку подключения.

Для подключения по IP, в основном используют программы для создания виртуальной локальной сети(RadminVPN или LogMeHamachi).

RadminVPN(Самый популярный вариант) Hamachi

Где найти игроков?

Phantasmagoria Netplay - Англоязычный Discord-сервер предназначенный для совместной игры в PoFV. Здесь вы можете найти игроков, участвовать в турнирах и просто пообщаться об игре.

При помощи Ctrl + (1-10) можно изменять задержку подключения прямо во время игры.

Не сворачивайте игру во время игры, т.к. это может привести к разрыву cоединения.
